# Агент wg-admin

Архив агента для ноды WireGuard — машины Linux (amd64 и arm64: платформу выбирает сам скрипт
`agent`): программы агента (`bin/`), настройки (`agent.yaml`, `agent.prod.yaml`,
`agent.docker.yaml`), воркеры `wg` (интерфейсы WireGuard, туннели, пробросы портов, пробы
связности) и `socks` (SOCKS5-прокси) под обе платформы и их подписанные сборки (`release/`).
Агент связывается с бэкендом сам — входящие порты ему не нужны (порты WireGuard и прокси
открывает воркер).

## 1. Адрес и токен

```bash
cp .env.example .env
```

Заполните `.env`: `AGENT_SERVER_URL` — адрес бэкенда, `AGENT_ENROLL_TOKEN` — токен регистрации
(выдаёт бэкенд), `AGENT_NAME` — имя агента. Если архив выдан для ноды, `.env` уже заполнен и агент
привяжется к ней. Без адреса и токена агент не запустится и напишет, чего не хватает
(`./agent config check --env prod`).

## 2. Запуск

Воркер `wg` настраивает сам узел (интерфейсы, маршруты, iptables, пересылку пакетов), поэтому
агенту нужны права root.

| Как                     | Команда                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------- |
| служба systemd          | `sudo ./agent install --env prod` — ставит wireguard-tools, iptables и др., `ip_forward`    |
| на месте, без установки | `sudo ./agent run --env prod` (пакеты — заранее)                                            |
| Docker Compose          | `docker compose up -d --build` — контейнер в сети узла (`network_mode: host`, `privileged`) |

После регистрации агент работает по своему ключу (в каталоге данных или томе), токен больше не
нужен — его можно удалить из `.env`.

## Управление

- состояние — `sudo agent-wg status` (служба), `docker compose exec agent ./agent status --env docker`;
- журнал — `journalctl -u agent-wg -f` или `docker compose logs -f`;
- удалить службу — `sudo agent-wg uninstall` (`--purge` — и данные; интерфейсы и правила,
  созданные воркером, убираются);
- обновить — новым архивом: та же команда установки или `docker compose up -d --build`.
