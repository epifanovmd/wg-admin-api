# Модуль wg-forward

Пробросы портов на релее до внешних сервисов, которыми wg-admin не управляет
(WireGuard-сервер в своём контейнере, SOCKS/TLS-прокси) — напрямую или через
IPIP-туннель до ноды-цели.

## Модель

**WgForward** (`wg_forwards`): name (unique), relayNodeId (FK RESTRICT),
protocol `udp|tcp`, listenPort (unique на релее в паре с протоколом),
цель — targetNodeId (нода с агентом, FK RESTRICT) и/или targetHost, targetPort,
path `direct|ipip`, route `auto|tunnel|direct`, enabled.

- `direct` — DNAT на targetHost (или publicHost ноды-цели).
- `ipip` — нужна нода-цель с агентом: она держит свой конец туннеля (линк
  релей → цель создаёт синхронизация релея модуля wg-interface — модуль
  регистрирует `asWgRelayConsumer`). DNAT на адрес цели внутри туннеля,
  прямой адрес — аварийный путь.
- `route`: `auto` — агент релея сам уходит напрямую, если туннель не отвечает
  несколько проб подряд (~30 с), и возвращается, когда ожил; `tunnel` /
  `direct` — принудительно (ручное переключение из UI).

Выключенный проброс порт на релее не держит: интерфейс можно перевести на
точку через релей на том же порту, а проброс оставить для отката. Включить
его можно, только пока порт свободен (409 `WG_FORWARD_PORT_TAKEN`); править
выключенный — можно всегда.

Проверки: цель обязательна; `ipip` без ноды — 400; цель = релей — 409;
порт занят другим пробросом, интерфейсом или точкой (UDP) — 409
`WG_FORWARD_PORT_TAKEN`; то же для процесса хоста по отчёту агента
(`osInfo.udpPorts/tcpPorts`), но только при создании включённого проброса и
смене порта: заранее созданный выключенный проброс можно включить, пока
порт ещё занят другим процессом — агент релея откажется применять и применит
сам в течение ~25 с после освобождения порта. Изменение поднимает версию
релея в транзакции.

Активный маршрут приходит в статистике агента (`forwards`) и хранится в
live-хранилище (TTL 60 с) — `activeRoute` в DTO.

## Эндпоинты (`/api/v1/wg/forwards`, тег WgForward)

CRUD; права `wg:forward:view` (чтение), `wg:forward:create`, `wg:forward:update`
(изменение, включение и маршрут), `wg:forward:delete`.

## Сокет

Комната `wg-forwards` (право `wg:forward:view`): `wg:forward:updated` (создание, изменение и смена активного маршрута по
отчёту агента — только при смене), `wg:forward:deleted`.
